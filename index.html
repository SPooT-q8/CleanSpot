## ❓ WHY_CLEANSPOT? Most cleaners just delete temp files and call it a day. CleanSpot goes further — it **shows you what's actually eating your disk**, **repairs a broken Windows install**, and **removes programs down to the last registry key**. One app, seven tabs, no subscriptions, no bloat. Built for gamers and power users, in **Arabic and English** — and sharp on any screen, from 100% to 150%+ scaling.
## ✨ CORE_FEATURES | MODULE | FUNCTIONALITY | |---|---| | 🧹 **System Cleaning** | Reclaim space across 20+ targets — Windows Temp, browser and shader caches, crash dumps, and more. Scan first, clean only what you pick. | | ◫ **Disk Analyzer** | A treemap of every folder, a duplicate finder verified with full SHA-256, big-file lists, and one-click cleanup suggestions. ## 🚀 DEPLOYMENT 1. Download **`CleanSpot_Setup_v2.4.exe`** from the [Releases page](../../releases/latest). 2. Run the installer and follow the steps. 3. Launch CleanSpot from the desktop shortcut or the Start Menu. > **SYS_UPDATE:** Already installed? The new version installs over the old one — your settings are kept. > **SECURITY_OVERRIDE:** CleanSpot isn't code-signed yet, so Windows may show a SmartScreen warning. Click **More info → Run anyway** — this is expected for new, unsigned apps. *REQUIREMENTS:* Windows 10 (1809) or later, 64-bit · Administrator rights.
## 🎯 INITIALIZATION (QUICK START) 1. Launch CleanSpot — it will request administrator access. 2. Review the cleaning targets; common-safe ones are enabled by default. 3. Click **SCAN ONLY** to preview, or **TURBO CLEAN** to clean now. 4. Explore the **Startup**, **Disk Analyzer**, **Uninstaller** and **Repair** tabs.
## 🛡️ SYSTEM_SAFETY - **Open source** — the released build can be reproduced from this code. - Every clean, uninstall and delete is written to a **daily log** (`%LOCALAPPDATA%\CleanSpot\logs`). - A **system restore point** can be created before uninstalling programs. - Disk Analyzer deletes go to the **Recycle Bin**, not permanent deletion. - **System files are protected** — pagefile, hibernation file, Windows and program folders never appear in the Big Files list. - **Destructive buttons are always red**, whatever theme you pick, so risky actions are easy to spot. - No kernel driver, no background service, no hardware-monitoring library.
